# 📊 Excel Production Dataset Dashboard

## 📌 Project Overview

This project is an interactive **Production Dataset Dashboard developed in Microsoft Excel**.

The dashboard analyzes production performance across different product types, managers, years, regions, gender groups, age groups, and quarters. It uses PivotTables, PivotCharts, and slicers to provide an interactive and user-friendly view of production data.

## 🛠️ Tools & Technologies

- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Slicers
- Data Cleaning
- Data Analysis
- Data Visualization
- Dashboard Development

## 📊 Dashboard Features

The dashboard includes the following visualizations:

### 1. Total Production Cost by Product Type
Compares the total production cost across:

- Automobiles
- Electronics
- Furniture
- Machinery

### 2. Number of Tasks by Manager
Shows the number of assigned tasks for each manager and helps identify managers handling a higher volume of tasks.

### 3. Total Units Produced by Year
Compares total production units across different years.

### 4. Average Production Cost per Unit by Product Type
Displays the average production cost per unit for different product categories.

## 🎛️ Interactive Filters

The dashboard contains interactive slicers for:

- Gender
- Region
- Age Groups
- Quarters

These filters allow users to dynamically explore different segments of the production data.

## 📈 Key Analysis Areas

The dashboard helps analyze:

- Production cost by product type
- Manager workload and task distribution
- Year-wise production volume
- Average production cost per unit
- Regional performance
- Gender-based analysis
- Age-group analysis
- Quarterly performance
